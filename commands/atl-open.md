---
description: Open the complete ATL Control Plane for this repository
argument-hint: [absolute repository path]
---
Open ATL for $ARGUMENTS, or the current application workspace when no path is supplied.
Use the bundled `atl_start` tool with the absolute application path. If no application
is identifiable, ask for its path; never select the plugin installation directory.
Open the returned URL using the harness browser capability. If that capability is
unavailable, provide the clickable URL. This is the full shared Control Plane,
including repository connections, models, previews, planning, execution and reviews.
Do not install ATL separately or start workers merely to open the interface.
