01 · TERMINAL TUI

Keyboard-first team room.

SSH · CI · compact live logs

Use the TUI for terminal, SSH, CI, and dense live state. It is the compatibility surface, not the browser Control Plane.

Open it

atl tui
atl dashboard --once --plain   # static output for logs / CI / SSH

Move around

Tab          next pane

c            compose work
x            queue or unqueue
l            launch preview
Enter / y    confirm bounded run
q            quit without changing state

BROWSER REFERENCE

Every Control Plane menu.

These pages read the local project through the Control Plane server. Empty states are normal in a new workspace. Opening a page or reviewing a preview does not start a run.

OverviewSee portfolio counts, active and blocked work, completed tasks, the lifecycle, recent activity and owner attention. Open a task or inspect blockers to investigate; Commands and CLI console provide shortcuts.
TasksCreate and inspect work. Search by task details, filter by status or queue, select visible tasks and archive selections. Open a task for its packet, evidence, actions and execution details; clearing the default queue removes its queue membership.
Plan StudioDescribe an objective and constraints, attach reference files, and generate editable task cards. Local preview is deterministic and offline. Model mode uses a ready provider and an explicitly confirmed planning session. Review and approve the plan before it becomes a queue; generation alone does not dispatch work. Text attachments enter planning context; images are recorded as references for the current text-only providers.
QueuesCreate and open workstreams, inspect tasks and progress, manage the active queue, and preview a run. Select multiple queues for a shared-budget run. The run preview shows the work and gates; starting requires confirmation. A running queue exposes Stop. Queue deletion and clearing change queue state.
Agent TeamSee each agent's role, observed status, current assignment and progress. Read agent briefs for details and use Agent events to open the activity timeline.
ProjectsRegister local repositories as project rooms, inspect their paths and concurrency limits, refresh the list, or remove registrations individually or in a selection. Each repository retains its own local ATL state.
ApprovalsReview action proposals, their status and recorded history. Approve a pending action once or deny it; inspect single-use grants and revoke an unused grant. A changed action or revision requires a new approval.
OperationsInspect session leases, scheduler and routine history, and backups. Create a project backup or choose Restore for an existing one. Check the target and confirmation before restoring state.
KnowledgeReview source-linked claims and freshness, approve eligible claims, validate or promote skills, and register routines. Routines start disabled and are approval gated; knowledge is advisory and does not replace task evidence or run confirmation.
Activity & LogsFilter the recorded timeline by actor, task, event or text, refresh the snapshot, and export activity. The connection indicator and capture time help distinguish live information from stale state.
Usage & LimitsReview local session observations alongside provider telemetry and its source and capture time. Refresh providers to probe supported adapters, or refresh the snapshot. Unreported quota remains unknown; local session counts are not a quota estimate.
SettingsManage provider profiles and built-in worker readiness, inspect execution defaults, configure the project-local codebase navigation map and token budget, and consult keyboard shortcuts. Provider availability affects model planning and execution readiness.

The top bar provides the command palette (Ctrl/Cmd + K), notifications, theme and New task. The sidebar provider status opens provider management; the command dock accepts supported ATL commands.

TERMINAL REFERENCE

Terminal navigation and actions.

The TUI has eight numbered navigation entries. Use the sidebar or keys 1?8; the terminal surface has its own controls and is not the browser interface.

1 ? OverviewReview the portfolio, selected task and team feed. Tab changes the focused pane; arrows or j/k move or scroll within it.
2 ? TasksInspect work and use task actions to compose, import, edit, review, attach resources, queue or unblock the selected task.
3 ? Plan StudioCompose a candidate from an outcome, inspect its packet and review its checks before creating work.
4 ? QueuesInspect queued work and its gate state, remove an item or open the launch preview. Confirm separately to run.
5 ? Agent TeamInspect the team and its current work and handoffs.
6 ? Activity & LogsRead state decisions and team narration; the logs view can follow the latest events.
7 ? Usage & LimitsInspect available usage and provider evidence.
8 ? SettingsInspect provider and configuration information and the available controls.

Useful keys include c to compose, e/v to edit or review, a to attach a resource, x to queue or unqueue, l to preview launch, Q for the execution queue, L for logs, p for providers, s for sessions, : for the command console, and Esc to go back. Press q to quit.
