# Agent Trust Ladder — راهنمای فارسی

ATL کار مهندسی را با تعریف کار، اجرای محدود، بازبینی مستقل و شواهد قابل بررسی هماهنگ می‌کند. مهارت‌های ایجنت و زمان‌اجرای محلی دو بخش جدا هستند.

## شروع کار

به Node.js نسخهٔ ۲۲ یا جدیدتر و Git نیاز دارید. [راهنمای نصب](docs/getting-started.md) مراحل نصب زمان‌اجرا و مهارت‌ها را توضیح می‌دهد. سپس در پروژهٔ مقصد اجرا کنید:

~~~sh
atl init
atl ui --port 4317
~~~

نشانی محلی چاپ‌شده را باز کنید و نام پروژه را بررسی کنید. باز کردن صفحه اجرای ایجنت را آغاز نمی‌کند.
