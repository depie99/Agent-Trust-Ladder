# Agent Trust Ladder — راهنمای فارسی

ATL کار مهندسی را با تعریف کار، اجرای محدود، بازبینی مستقل و شواهد قابل بررسی هماهنگ می‌کند. پلاگین کامل، مهارت‌ها، workflowها، اجرای تسک‌ها و Control Plane را در یک بسته عرضه می‌کند.

برای Codex، Claude Code، Cursor، DeepSeek Harness، Gemini CLI و هارنس‌های دارای MCP محلی با `npm run plugins:build` بسته بسازید. خروجی در `dist/plugins/` قرار می‌گیرد و به نصب جداگانهٔ ATL یا تغییر PATH نیاز ندارد. در هر بسته، `start.cmd` در ویندوز یا `sh start.sh` در لینوکس و مک، دستیار اتصال ATL Connect را باز می‌کند: انتخاب هارنس، کپی تنظیمات، رابط فارسی و انگلیسی با حالت روشن و تیره، و ورود مستقیم به پنل کنترل پروژه. داخل پلاگین هم ابزار `atl_connect` همین تجربه را ارائه می‌دهد. بسته‌ها هنوز در marketplaceهای عمومی منتشر نشده‌اند. [راهنمای پلاگین کامل](docs/getting-started.md#use-the-complete-plugin) روش استفاده و مرز پشتیبانی را توضیح می‌دهد. روش نصب مستقل هم در ادامه در دسترس است.

## شروع کار

به Node.js نسخهٔ ۲۲ یا جدیدتر و Git نیاز دارید. [راهنمای نصب](docs/getting-started.md) مراحل نصب زمان‌اجرا و مهارت‌ها را توضیح می‌دهد. سپس در پروژهٔ مقصد اجرا کنید:

~~~sh
atl init
atl ui --port 4317
~~~

نشانی محلی چاپ‌شده را باز کنید و نام پروژه را بررسی کنید. باز کردن صفحه اجرای ایجنت را آغاز نمی‌کند.
