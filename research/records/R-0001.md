## Summary

Matt Pocock's skills repo v1.3 adds three daily-driver skills:

- `/implement-spec` — treats a ticket list as a dependency graph, runs ready
  tasks in parallel git worktrees, integrates the results, and finishes with
  a code review pass.
- `/retro` — improves the agent environment based on what previous sessions
  struggled with, turning retrospective observations into environment changes.
- `glossary.md` — shared vocabulary file so agents and humans use the same
  terms.

## Why it matters to ATL

This is the same shape as ATL's queue + launch loop, but with explicit
dependency edges between tasks and integration validation at the end —
both are gaps in the current FIFO ordering. The worktree-per-task model
matches ATL's `workspace <id>` isolation.

## ATL recommendation

P0: adopt dependency-aware scheduling (task.depends_on + readiness view),
keep worktree isolation, and add integration validation to the launch
queue's end-of-run step. Feed `/retro`'s idea into ATL's retrospective
backlog ticket.
